# Git Basics

## Basic Workflow

```bash
git pull   #Downloads and integrates changes from the remote repository.
git status #Shows the current state of the repository.
git diff   #Shows changes made to files.
git add .  #Moves changes to the staging area.
git commit -m "Commit message" #Creates a snapshot of staged changes.
git push   #Uploads local commits to GitHub.


Ya conocés prácticamente todos esos conceptos por el curso que acabás de hacer.
